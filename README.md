## Deloitte-AI-Sustainability

# Overview

This project is a lightweight Android prototype built in Kotlin that explores how simple, data-driven workflows can encourage more sustainable behavior. The app collects basic user inputs and provides tailored sustainability recommendations.

# What I Built

A multi-screen Android application using Activities and Intents

User input handling and validation for numerical data

Rule-based recommendation logic for:

- Waste reduction (plastic usage)

- Carbon footprint awareness (travel distance)

- Dynamic UI updates based on user input and computed results

# Technical Focus

- Kotlin

- Android SDK

- UI layouts with XML

- Event handling and conditional logic
